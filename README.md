# Pawly - Pet Clinic
Pawly adalah website pet clinic yang menyediakan informasi mengenai layanan kesehatan dan perawatan hewan.

## Fitur
* Home
* About Pawly
* Services
* Daftar dokter hewan
* Contact dan form pesan
* Responsive untuk desktop, tablet, dan mobile

## Teknologi
* HTML
* CSS
* JavaScript (DOM)
